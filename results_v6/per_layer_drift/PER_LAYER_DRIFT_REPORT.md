# CHMC v6.4 — Per-Layer Drift Decomposition: ОТРИЦАТЕЛЬНЫЙ РЕЗУЛЬТАТ (STOP)

**Дата:** 2026-08-18 · **Модель:** SmolLM-135M · **Baseline:** strict_damp005 seed42 (CPU-rerun)
**Вердикт по гейту Шага 1: FAIL → STOP. Шаги 2–4 не выполнялись.**

---

## Гипотеза и гейт (объявлены ДО данных)

Суммарный дрейф модели высокоразмерный (d90 = 227–792 на блоках,
`results_v6/drift_correction`). Гипотеза: **per-layer вклад каждого слоя
низкоразмерен** — каждый слой добавляет малый шум, сумма по 30+ слоям даёт
высокоразмерный остаток. Тогда возможна селективная компрессия: сжимать только
«безопасные» слои (D_l ≤ ε−γ), остальные держать FP16.

**Гейт:** ≥50% из 210 сжимаемых слоёв имеют `local d90 < 30` → PASS, иначе STOP.

## Методика

- **LOCAL drift (тест гипотезы):** `D_loc,l = X_fp,l · E_lᵀ`, где
  `E_l = W_fp − W_comp` — чистый вклад слоя на чистом FP-входе, тот же
  X_calib (2048 токенов wikitext-train), что и в квантизации. Считается без
  доп. forward-проходов.
- **ACCUMULATED drift (вторично):** hooks на входы/выходы всех слоёв, один
  forward FP + один forward сжатой модели: `acc_in = post_in − pre_in`
  (состояние, входящее в слой), `acc_out = post_out − pre_out`.
- **d90:** мин. k с cumsum(s²)/Σs² ≥ 0.90, полный SVD (float64) от
  центрированной D — конвенция TDA/drift_correction.
- Квантизация воспроизводит baseline ТОЧНО как `run_chmc_v6` seed42: тот же
  порядок слоёв и калибровки, один `torch.manual_seed(42)` в начале,
  `strict_sequential=True, dampening=0.05, group_dim=0, niter=5`, BPW ≤ 4.2875
  (ranks 1–4). PPL не считается (inference не потребляет RNG → поток для
  svd_lowrank идентичен GPU-прогону; сами веса на CPU отличаются от GPU-rep0
  на уровне недетерминизма BLAS/SVD — на структуру дрейфа это не влияет).

**Конвенция rel_disp:** в JSON `rel_disp_user` = mean‖d‖/mean‖вход‖ (буквальная
формула из промпта), но осмысленная величина — относительно **выхода слоя**:
`acc_out.rel_disp_user` (= mean‖d‖/mean‖out‖). Для слоёв блока 0 acc_out ≡ local.

## Результаты

| Метрика | min | p25 | медиана | p75 | max |
|---|---|---|---|---|---|
| **local d90** (гейт) | 9 | 123 | **230.5** | 316 | 339 |
| acc_in d90 | 0 | 300 | 321 | 344 | 649 |
| acc_out d90 | 15 | 121 | 203 | 312 | 359 |

- **Доля слоёв с local d90 < 30: 1/210 = 0.5%** (нужно ≥50%) → **FAIL**.
  Даже при порогох <50 / <100 / <150 доля 0.5% / 2.9% / 34%. Чтобы получить
  50%, порог пришлось бы ставить ≈240 — т.е. «всё низкоразмерное».
- Медианный local d90 по блокам: blk0 = 85, blk1–28 ≈ 220–247 (плоско),
  blk29 = 159. LOCAL дрейф не растёт с глубиной — он высокоразмерный уже в
  каждом отдельном слое.
- ACCUMULATED: acc_in d90 = 0 для q/k/v_proj блока 0 (embeddings не сжимаются →
  вход не меняется; проверка корректности пайплайна), затем ~29–382 к концу
  blk0, медиана по модели 321. Суммирование слоёв делает дрейф ещё более
  высокоразмерным — как и предсказывало «D_model = Σ D_l» при высокоразмерных D_l.
- Низкоразмерный local drift есть только там, где слой почти весь в low-rank
  части: bottom-12 по d90 — rank-1/2 k/v/o_proj (d90 56–113), единственный
  прошедший гейт — L0.o_proj (rank 2, d90 = 9).
- **Магнитуда дрейфа мала, размерность велика:** для блока 0 (чисто local)
  относительно выхода слоя: q/k/v/o 1.7–7.4%, gate/up/down 6.8–10.4%. По всей
  модели медиана out_rel = 0.176, max 0.329 (включая накопленный вклад).

## Почему гипотеза не сбылась (механизм)

E_l = R − R_q — ошибка квантизации резидуали после GPTQ-компенсации.
Sequential compensation минимизирует ‖X·E‖²_F, **распределяя** ошибку
округления по всем активным входным направлениям (ошибка каждого столбца
переносится в последующие). Результат: малая по норме, но почти изотропная в
активационном пространстве матрица дрейфа → d90 ≈ 230 при out_rel ~2–10%.

Иными словами: **именно тот механизм, который делает CHMC v6 качественным
(компенсация), разрушает низкоразмерность per-layer дрейфа**. Без компенсации
ошибка была бы крупнее по норме, но структурно (возможно) низкоранговой — это
другой trade-off, не тестируемый здесь.

## Выводы и последствия для плана v6.4

1. **STOP:** селективная компрессия по критерию размерности безопасности
   («D_l ≤ ε−γ в low-rank смысле») на SmolLM для baseline CHMC v6 невозможна —
   99.5% слоёв не проходят даже порог d90 < 30.
2. Шаги 2–4 (калибровка ε−γ шумовым семейством, селективная компрессия, TDA-
   кроссчек) отменяются: их входное допущение (низкоразмерный per-layer дрейф)
   ложно.
3. Если селективность всё же нужна — прокси должен быть **магнитудным**
   (out_rel, lr_energy_pct), а не размерностным; это другая гипотеза и другой
   эксперимент (например: слои с малым out_rel можно квантовать агрессивнее /
   держать FP16, проверяя PPL при равном BPW).
4. Ограничение: SmolLM только. Модель-зависимость CHMC vs GPTQ уже известна;
   структура per-layer дрейфа на Qwen/TinyLlama не проверялась (правило STOP
   объявлено для данного плана).
